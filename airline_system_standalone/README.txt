AIRLINE REGISTRATION SYSTEM - STANDALONE

This version does NOT require SQL Server, SSMS, MySQL, XAMPP, or any server.

Requirements:
- Python 3.10+ recommended
- Internet only for installing Python packages the first time

RUN:
1. Open Command Prompt in this folder.
2. Run:
   pip install -r requirements.txt
3. Run:
   streamlit run app.py
4. Open the URL shown by Streamlit, usually:
   http://localhost:8501

The database is automatically created as airline.db in this folder on first run.
Sample passenger, flight, booking and payment data are also created automatically.
